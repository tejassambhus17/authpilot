The local image-viewing tool cannot decode ICO files. Confirm rendering and decode in the application's browser verification pass; valid file headers alone do not certify their rendered appearance.

Unknown providers retain a generic icon until an official asset has been sourced and reviewed. Mapping uses exact normalized provider names; arbitrary research-result images are never treated as trusted brand assets.
